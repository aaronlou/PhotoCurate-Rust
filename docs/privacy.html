隐私政策

最后更新日期：2026 年 5 月 26 日

1. 概述

PhotoCurate（以下简称「本应用」）是一款本地运行的桌面软件，致力于保护您的隐私。本隐私政策说明本应用如何处理您的数据。

本应用的核心理念是：所有数据默认存储在您的设备上，未经您明确授权不会将数据发送到任何外部服务器。

2. 本应用不收集的信息

为消除疑虑，本应用明确不收集以下任何信息：

  • 不收集个人身份信息（姓名、邮箱、电话号码等）
  • 不收集设备信息或系统配置
  • 不收集崩溃日志或诊断数据
  • 不收集使用统计或分析数据
  • 不收集位置信息
  • 不含任何广告 SDK 或跟踪框架
  • 不含任何遥测或数据上报机制

本应用没有用户账户系统，没有云端同步功能，没有分析后台。

3. 本地存储的数据

以下数据仅存储在您的设备上：

  • 已添加的照片文件夹路径：您通过系统对话框选择的目录
  • 照片元数据：从 EXIF 提取的拍摄日期、相机型号、光圈、快门等
  • AI 评分结果：照片的美学评分（0-100 分）
  • AI 搜索索引：图像向量嵌入数据（用于语义搜索）
  • 缩略图缓存：照片缩略图文件
  • API Key 状态：是否已配置 Gemini API Key；实际 Key 存储在 macOS Keychain 中，不写入本地 SQLite 数据库

所有这些数据完全存储在您的设备上，您可以随时删除应用及其数据目录来清除所有数据。

4. 发送到外部服务的数据（需您主动配置）

以下情况涉及将数据发送到外部服务器，每项均需您主动配置或触发：

AI 照片美学评分（可选）

触发条件：您主动点击「开始评分」按钮。
数据内容：照片文件被发送至 Google Gemini API (generativelanguage.googleapis.com) 进行分析。
传输方式：HTTPS 加密。
数据留存：Google 的 API 使用政策见 Gemini API Terms。

中文语义搜索（可选）

触发条件：您的搜索查询。
方式 A（Gemini API）：搜索文本发送至 Gemini API 进行向量化。
方式 B（本地模型）：使用本地 Chinese-CLIP 模型，数据不离开设备。

自动图像索引（可选）

触发条件：您添加新照片文件夹后自动执行。
方式 A：照片发送至 Gemini API 生成文字描述再向量化。
方式 B：使用本地模型，数据不离开设备。

API Key 验证

触发条件：您保存 Gemini API Key 设置时。
数据内容：仅发送测试请求以验证 Key 有效性。

如果您不配置 Gemini API Key 且安装本地 Chinese-CLIP 模型，则不会有任何数据离开您的设备。

5. 第三方服务

本应用唯一涉及的外部服务是 Google Gemini API，且仅在您主动提供 API Key 时才会使用。Google 的隐私政策适用于通过其 API 传输的内容，请参阅 Google Privacy Policy。

6. 数据安全

  • 所有本地数据存储在您的设备上，使用 SQLite 格式
  • 与 Gemini API 的通信使用 HTTPS 加密
  • 本应用不传输、不备份、不同步您的数据到任何云端
  • 您的 API Key 存储在 macOS Keychain 中，不会上传给开发者

7. 用户权利

由于所有数据均存储在您设备本地，您拥有对数据的完全控制权：

  • 在应用内删除照片文件夹或移除照片，随时清除数据
  • 删除 ~/Library/Application Support/com.photocurate/ 目录即可清除所有本地数据
  • 本应用开发者无法访问您的本地数据，因此无法代为删除或导出

8. 本政策的变更

本隐私政策可能不时更新。新版本将在本页面发布，并更新「最后更新日期」。如需进行重大变更，我们将通过应用更新说明或 GitHub Release 通知。
