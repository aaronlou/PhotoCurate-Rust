三大核心功能

你的摄影作品库，由 AI 接管管理

AI 美学评分

基于 Gemini AI 自动为每张照片打分（0-100 分），从构图、光线、色彩、技术质量多维度评估。进度条实时更新，批量处理无需等待。

中文语义搜索

用自然语言描述画面内容直接搜索——「夕阳下的海滩」「穿红衣服的小孩」。基于 Chinese-CLIP 本地模型，无需联网即可检索全部照片。

精选导出

设定评分阈值，一键导出所有高分作品。支持保持原始文件夹结构，文件名冲突自动重命名。告别一张张挑选的繁琐流程。

使用流程

从导入到导出，四步完成照片精选

1

导入文件夹

选择本地照片目录，自动扫描并生成缩略图。索引在后台自动建立。

2

AI 评分

配置 Gemini API Key，一键批量评分。进度条实时更新，每张照片都有详细评语。

3

智能检索

输入中文描述，AI 在照片内容中匹配最相关的结果。索引全自动，无需额外操作。

4

精选导出

选择评分门槛，一键导出全部高分作品。支持保持目录结构。

推荐

Gemini API

零配置，开箱即用。免费额度足够日常使用。负责美学评分和语义搜索。

  • ✓ 无需下载模型
  • ✓ 评分 + 搜索全覆盖
  • ✓ 免费额度足够

本地 Chinese-CLIP 模型

完全离线运行，数据不出本机。Apple Silicon 上使用 CoreML 加速推理。

  • ✓ 隐私优先，零网络依赖
  • ✓ CoreML 硬件加速
  • ✓ 支持语义搜索

开始使用

3 步在本地启动 PhotoCurate

环境要求

Node.js ≥ 20  |  Rust ≥ 1.78  |  macOS 14.0+

1. 克隆仓库
git clone https://github.com/aaronlou/PhotoCurate-Rust.git && cd PhotoCurate-Rust
2. 安装依赖 & 启动
npm install && npm run tauri-dev
3. （可选）配置本地模型

在应用评分页设置 Gemini API Key，或参考 README 下载 Chinese-CLIP 本地模型。
